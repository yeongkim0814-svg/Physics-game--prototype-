# Physics Skill Game

물리 법칙 자체가 능력인 웹 기반 3D 익스트랙션 슈터 (Three.js + Vite + TypeScript).

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
```

## 조작 (Phase 0)

**PC**

| 입력 | 동작 |
| --- | --- |
| 화면 클릭 | 포인터 잠금(시작) |
| WASD | 이동 |
| 마우스 | 시점 |
| Shift | 달리기 |
| E | 터널링 |
| Q | E=mc² 소멸 |
| Esc | 포인터 해제 |

**태블릿/폰 (가로 모드 권장)**

| 입력 | 동작 |
| --- | --- |
| 화면 터치 | 시작 (가능하면 전체화면+가로 고정) |
| 왼쪽 절반 드래그 | 가상 조이스틱: 밀기 정도에 따라 속도 조절 (끝까지 밀기 = 스프린트) |
| 오른쪽 절반 드래그 | 시점 |

**자동 달리기**: 스틱을 위로 쭉 올리면 🏃 아이콘이 나타납니다. 아이콘에 맞추고 손을 떼면 전력질주가 유지되고, 스틱을 다시 터치하면 해제됩니다.

## 규칙 (Phase 1)

- 에너지 100 중 30으로 시작, 자연 회복 없음.
- 방 곳곳의 발광체에 닿으면 흡수: 작은 것 +10, 큰 것 +25. 에너지가 가득 차면 줍지 않고 남겨 둡니다.

## 터널링 스킬 (Phase 2)

- 발동: PC `E`, 터치 우하단 버튼. 시선 방향 1.6m 안의 **푸른 벽**(두께 L)이 대상이며, 조준하면 확률이 표시됩니다.
- 확률: `T = e^(-2κL)`, `κ = 22 / (현재 에너지)`. 에너지가 많고 벽이 얇을수록 높습니다.
- 비용: 15⚡ (실패해도 소모). 성공 시 반대편으로 통과, 실패 시 반사되어 밀려납니다. 반대편이 막혀 있으면 시도할 수 없습니다.

## E=mc² 스킬 (Phase 3)

- 발동: PC `Q`, 터치 우하단 왼쪽 버튼. 시선 6m 안의 **황갈색 상자**(질량 1~3kg)를 조준하면 얻는 에너지와 폭발 반경이 표시됩니다. 벽 뒤의 상자는 조준할 수 없습니다.
- 에너지: `E = mc²`, c² = 10⚡/kg. 질량 전부가 에너지가 되어 충전됩니다(비용 6⚡). 에너지가 가득 차 있으면 쓸 수 없습니다(자원과 같은 규칙).
- 폭발: 반경 `R = 0.55·√E`. 중심에 가까울수록 플레이어가 세게 밀려납니다(거리 선택이 전술). 반경 안의 다른 상자는 충격파 속도(9m/s)에 맞춰 **연쇄 소멸**하며 각각 에너지를 줍니다.
- 상자는 길을 막는 충돌체라, 소멸시키면 새 길이 열립니다. 왼쪽 틈의 상자 두 개로 연쇄를 시험할 수 있습니다.
- 사운드는 아직 없습니다(추후 추가).

## 적 (Phase 4)

| | 감시병 | 사냥개 |
| --- | --- | --- |
| 이동 | 느림 (순찰 1.3 / 추격 2.8) | 빠름 (순찰 2.2 / 추격 5.6) |
| 시야 | 넓고 짧음 (110°, 6m) | 좁고 김 (55°, 9m) |
| 반응 | 느림 (0.9s) | 빠름 (0.45s) |
| 접촉 피해 | 20 | 12 |

- 상태: 순찰(Idle) → 의심(Alert, `?`) → 추격(Chase, `!`). 바닥의 반투명 콘이 실제 시야(벽/상자에 가려진 만큼 잘림)입니다.
- 발소리: 달리면 3.5m, 걸으면 1.6m, 멈추면 0.8m 안에서만 들립니다.
- 폭발(E=mc²)은 범위 안의 적에게 거리 감쇠 피해(에너지×4)를 주고, 멀리 있는 적도 소음을 듣고 조사하러 옵니다.
- 체력 100, 피격 후 1초 무적. 0이 되면 "신호 소실" 화면에서 다시 시작합니다.

## 그래픽

"낡은 산업 시설, 늦은 밤" 콘셉트의 PS1 레트로 룩: 480×270 저해상도 렌더 → 깊이 윤곽선·탁한 색보정·비네팅·그레인·디더링 후처리 → CSS로 픽셀 확대. 청록 줄무늬 벽이 터널링 가능한 벽입니다. 폰트는 Galmuri11(SIL OFL 1.1).

## 구조

- `src/engine/GameEngine.ts` — 고정 60Hz 로직 + 보간 렌더 루프
- `src/player/` — 입력, 플레이어(이동/충돌)
- `src/level/` — 방, 벽, 소멸 가능한 상자, AABB 충돌 데이터
- `src/render/` — 팔레트, 정점 스냅, 후처리, 절차적 텍스처
- `src/skills/` — 터널링·E=mc² 스킬, 입력, 파티클(충격파 포함)
